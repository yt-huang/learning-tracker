# Learning Tracker Product Review

## 状态：5 项核心需求已完成并部署 ✅

## 待打磨的产品问题

### CRITICAL（必须修）
1. **index.html:18 密码默认值**
   - `<input id="password" value="admin" />` → 应改为空字符串，防止自动填充泄露
2. **登录失败后错误信息不清除**
   - 第二次输入错误密码会追加错误信息
3. **无 token 过期提醒**
   - session 7 天过期但没有任何提示

### MAJOR（建议修）
4. **无加载状态指示器**
   - 登录、保存、分析链接时无 loading spinner
5. **任务不能单独编辑**
   - 拖动进度条是最基本的，但没法编辑任务的标题/描述/预计时间
6. **空状态引导不足**
   - 首次使用时 dashboard/plans 都显示"暂无计划"，没有引导创建

### MINOR（可修可不修）
7. **进度滑块使用浏览器默认样式**
   - `<input type="range">` 没有自定义 CSS
8. **无进度颜色区分**
   - 进度条全是蓝色，<30% 红色 / 30-70% 黄色 / >70% 绿色 更直观
9. **Toast 没有任何动画**
   - 单纯的 hide/show，没有淡入淡出
10. **无快捷返回顶部按钮**
    - 计划详情页比较长时用户体验差
