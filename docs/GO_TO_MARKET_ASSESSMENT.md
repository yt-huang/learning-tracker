# Learning Tracker · 上线评估报告

## 技术层面：能否上线？

### ✅ 正面

| 指标 | 数据 | 评价 |
|------|------|------|
| 内存占用 | 13MB Docker | 极其轻量，1G服务器跑100个没问题 |
| CPU | 0.01% idle | 几乎无开销 |
| 服务器负载 | 4核 / 3.4GB | 远低于极限 |
| 代码规模 | ~3000行 | 可控，单人可维护 |
| 运行稳定性 | Docker + restart:always | 自动重启 |
| 零外部依赖 | Python stdlib only | 无版本冲突风险 |
| 数据持久化 | IndexedDB + SQLite | 离线可用 |

### ❌ 不可上生产的硬伤

#### 1. 无 HTTPS（最严重）
所有数据明文传输，密码、学习内容全部可被中间人劫持。

#### 2. 单用户设计
admin/admin123 硬编码，无注册 / 多用户 / 权限体系。多一个人用就要改代码。

#### 3. 前端数据不抗丢
SQLite 在浏览器 IndexedDB 中，**清除浏览器数据 = 丢失所有学习记录**。没有云同步。

#### 4. 无 CSRF / XSS 防护
`innerHTML` 多处直接拼接用户输入，虽然目前只有 admin 自己能操作，但如果有 XSS 入口就全站沦陷。

#### 5. 无日志 / 监控 / 告警
服务器 crash 了没人知道，没有指标采集。

#### 6. 无备份机制
用户得手动导出 .db，没有自动备份。

## 产品价值：上线后有价值吗？

### 目标用户画像

| 类型 | 会不会用 | 原因 |
|------|---------|------|
| **本人 / 个人学习者** | ✅ 会 | 自己记录学习进度，够了 |
| **身边朋友** | ❌ 不会 | 要部署，门槛高，不如用 Notion |
| **企业/团队** | ❌ 不会 | 没权限、没协作、没API |
| **开源社区** | 🤷 也许 | 如果能一键部署 + Docker Hub |

### 与竞品对比

| 维度 | Learning Tracker | Notion + 模板 | 飞书知识库 | Obsidian |
|------|-----------------|---------------|-----------|----------|
| 部署成本 | 要服务器 | SaaS 即用 | SaaS 即用 | 本地免费 |
| 学习计划生成 | ✅ AI 自动生成 | ❌ 手动建 | ❌ 手动建 | ❌ 手动建 |
| 进度跟踪 | ✅ 滑块/百分比 | ✅ 可做 | ✅ 可做 | ⚠️ 插件 |
| 数据归属 | 浏览器 SQLite | 云端 | 飞书 | 本地 |
| 多端同步 | ❌ 无 | ✅ | ✅ | ⚠️ 付费 |
| 多用户 | ❌ 单用户 | ✅ | ✅ | ❌ |
| 离线可用 | ✅ | ⚠️ | ❌ | ✅ |
| 美观度 | ⚠️ 一般 | ✅ 精致 | ✅ 精致 | 🤷 |

### 核心差异点

AI 自动从学习链接生成阶段化计划 — **这个功能是竞品没有的**。Notion 模板要手动建，Obsidian 要手动写。

### 结论：有价值，但不适合「直接上线卖」

## 建议路线

### 方案 A：个人工具（推荐你现在做的）

**定位**：自己用 + GitHub 展示 + 朋友尝鲜

**改成什么**：
- 不叫"上线"，叫"部署"
- 加 Docker Hub 一键部署脚本
- 写 README / 展示截图
- 适合简历 / 博客展示项目

**门槛极低，价值明确**。

### 方案 B：SaaS 产品（如果想认真做）

**需要加的功能**：

| 优先级 | 功能 | 预估工时 |
|--------|------|---------|
| P0 | HTTPS + 域名 | 1天 |
| P0 | 多用户注册/登录 (JWT) | 3天 |
| P0 | 后端 SQLite (不是浏览器的) | 2天 |
| P1 | Cloud sync (多个设备共用数据) | 3天 |
| P1 | 分享计划（只读链接） | 1天 |
| P2 | 邮件/推送提醒 | 2天 |
| P2 | API 公开 | 1天 |
| P3 | 微信小程序 | 5天 |

**毛利模型**：
- 月活 1000 用户，服务器成本 ~50元/月
- 免费版：10个计划限制
- Pro 版 9.9元/月：无限计划 + AI 深度分析 + 云同步
- 月入 1 万需 ~1000 个付费用户

**风险**：Notion / 飞书 / Obsidian 都是巨无霸竞品，除非 AI 分析做到极致（比如自动跟进课程更新、推荐最佳学习路径），否则很难差异化。

### 方案 C：开源项目

**定位**：AI-Powered 个人学习计划工具，对标
- https://github.com/features/code-search 的学习跟踪
- 类似 `https://github.com/nicedad/learning-tracker` 之类

**可以加**：
- GitHub Actions 自动部署到自己的服务器
- Docker Compose one-command 部署
- 多语言支持
- 贡献者指南

## 我的建议

**现在就上线**（指部署到服务器给朋友看），**不要当商业产品卖**。

原因：
1. 单用户 + 浏览器 SQLite 决定了它是个个人工具，不是多租户SaaS
2. AI 分析目前是 fallback 模式（没配 Key），真正 AI 要花钱
3. 竞品太强，做 SaaS 需要至少 2-3 个月全职投入

**最好的用法**：
- 放在 GitHub 作为作品集项目
- 自己日常用（记学习日志确实方便）
- 想要时打开 Docker 跑一下
- 给朋友演示 AI 生成计划的能力

这就是一个很好的 **作品集+自用工具**，不是创业项目，不必勉强它变成商业产品。
