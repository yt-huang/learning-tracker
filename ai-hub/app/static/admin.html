Internal AI Gateway

AI 分析管理后台

在页面里输入 API URL 和 Key，保存到 MySQL，统一管理 OpenCode Go / DeepSeek / OpenAI 等 OpenAI-Compatible Provider、模型和调用日志。

管理员登录

默认账号：admin / admin。首次进入后直接在页面配置 API URL、Key 和模型。


    


    

      

        
        
        
        
      


      

        
页面配置：OpenCode Go / DeepSeek / OpenAI

        
    
          
  1. 进入 Provider：输入名称、API URL（Base URL）和 API Key，点击保存。
    2. 
          
  2. OpenCode Go 示例 API URL：https://opencode.ai/zen/go/v1
    3. 
          
  3. 保存后 Key 会加密写入 MySQL，不需要在 Docker 环境变量里传第三方模型 Key。
    4. 
          
  4. 进入 Models：手动添加 deepseek-v4-pro，或从 API 拉取后批量导入，并勾选默认模型。
    5. 
          
  5. 点击"测试默认模型"，返回 pong 即配置成功。
    6. 
        

        
Docker Compose 默认已内置 MySQL

  environment:
    AI_HUB_URL: http://ai-hub:8020
    AI_HUB_TOKEN: dev-internal-token

curl -X POST http://127.0.0.1:8020/api/v1/analyze-learning-link \
  -H 'Authorization: Bearer dev-internal-token' \
  -H 'Content-Type: application/json' \
