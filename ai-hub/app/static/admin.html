Internal AI Gateway

AI 分析管理后台

统一管理 OpenCode Go / DeepSeek / OpenAI 等 OpenAI-Compatible Provider、模型和 Key，并给内网业务系统提供分析 API。

管理员登录

默认账号：admin / admin。生产环境请通过 Docker 环境变量修改。


    


    

      

        
        
        
        
      


      

        
推荐配置：OpenCode Go

        
    
          
  1. 添加 Provider：OpenCode Go
    2. 
          
  2. Base URL 填：https://opencode.ai/zen/go/v1
    3. 
          
  3. API Key 填 OpenCode Go 的 Key，保存后不会明文展示。
    4. 
          
  4. 添加模型：deepseek-v4-pro，勾选默认模型。
    5. 
          
  5. 点击"测试默认模型"，返回 pong 即配置成功。
    6. 
        

        
Docker Compose 内网调用

        
learning-tracker:
  environment:
    AI_HUB_URL: http://ai-hub:8020
    AI_HUB_TOKEN: ${AI_HUB_INTERNAL_TOKEN}

        
内部 API 示例

        
curl -X POST http://127.0.0.1:8020/api/v1/analyze-learning-link \
  -H 'Authorization: Bearer dev-internal-token' \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://github.com/yt-huang/learning-tracker","goal":"学习架构","level":"进阶","hoursPerWeek":5}'
